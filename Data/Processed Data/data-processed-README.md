# 📂 Processed Data

This folder contains the **cleaned, validated, and feature-engineered** version of the used-vehicle sales dataset, produced from the raw data in `data/raw/`.

## File(s)

| File | Description |
|---|---|
| `vehicle_clean.csv` | Cleaned, analysis-ready dataset used for SQL analysis and the Power BI dashboard |

> ⚠️ Update the filename above to match your actual processed data file. This is also the table referenced as `vehicle_clean` in `sql/analysis_queries.sql`.

## How This Was Produced

Generated by running the cleaning and feature-engineering steps in `notebooks/cleaning_and_eda.ipynb` against the raw file in `data/raw/`. To regenerate this file from scratch, re-run that notebook end-to-end.

## Cleaning Steps Applied

- Removed duplicate records and duplicate VINs
- Handled missing values
- Standardized categorical text fields (`make`, `body`, `color`, `interior`) — trimmed whitespace and normalized casing
- Validated and cleaned numerical fields (`odometer`, `mmr`, `sellingprice`)
- Parsed and standardized `saledate` into a consistent date format
- Flagged/removed invalid or out-of-range values

## Schema — Original Columns (Cleaned)

| Column | Description |
|---|---|
| `year` | Vehicle manufacturing year |
| `make` | Vehicle manufacturer (standardized) |
| `model` | Vehicle model |
| `trim` | Vehicle trim/version |
| `body` | Vehicle body type (standardized) |
| `transmission` | Transmission type |
| `vin` | Vehicle Identification Number (deduplicated) |
| `state` | State where vehicle was sold |
| `condition` | Vehicle condition |
| `odometer` | Vehicle mileage (validated) |
| `color` | Exterior color (standardized) |
| `interior` | Interior color (standardized) |
| `seller` | Seller/dealer |
| `mmr` | Market reference value |
| `sellingprice` | Final selling price |
| `saledate` | Standardized sale date |

## Schema — Engineered Columns

| Column | Description |
|---|---|
| `Vehicle Age` | `saledate.year − year` — vehicle age at time of sale |
| `Mileage Band` | Bucketed odometer ranges for segment-level analysis |
| `Pricing Status` | Above MMR / At MMR / Below MMR classification |
| `Premium %` | `(Selling Price − MMR) / MMR × 100` — normalized pricing performance vs. market reference |
| `SaleDate_Clean` | Fully standardized, validated sale date used for time-based analysis |

## Used By

- `sql/analysis_queries.sql` — loaded into MySQL as the `vehicle_clean` table
- `powerbi/vehicle_analytics.pbix` — primary data source for the dashboard
